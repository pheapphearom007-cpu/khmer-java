# Khmer Java Academy (បណ្ឌិត្យសភាភាសា Java ជាភាសាខ្មែរ) ☕🇰🇭

**Khmer Java Academy** គឺជាវេទិកាសិក្សាភាសា Java ពេញលេញ និងឆ្លើយតបគ្រប់ឧបករណ៍ (Responsive) ដែលត្រូវបានបង្កើតឡើងយ៉ាងយកចិត្តទុកដាក់សម្រាប់សិស្ស-និស្សិត និងអ្នកចាប់ផ្តើមដំបូងនៅកម្ពុជា។ វេទិកានេះជួយឱ្យអ្នកសិក្សាឈានពីកម្រិតសូន្យ រហូតដល់អាចសរសេរកូដ ដោះស្រាយបញ្ហា (Debug) និងកសាងកម្មវិធីជាក់ស្តែងដោយខ្លួនឯង។

---

## 🌟 លក្ខណៈពិសេសស្នូល (Core Features)

1. **Khmer-First Interface & Localization:**
   - ចំណុចប្រទាក់ជាភាសាខ្មែរតាមលំនាំដើម ព្រមទាំងមានប៊ូតុងប្តូរទៅជាភាសាអង់គ្លេសភ្លាមៗ (Khmer-first with English switch)។
   - អក្សរខ្មែរងាយស្រួលអានជាមួយ Google Fonts: *Noto Sans Khmer* និង *Kantumruy Pro*។
   - រចនាឡើងតាមបែប Mobile-first, Dark/Light Mode, និងពណ៌ក្រហមតំណាង Java Red Accents។

2. **W3Schools Aligned Curriculum & Original Khmer Content:**
   - រចនាសម្ព័ន្ធមេរៀនស្របតាម **W3Schools Java Tutorial** និងមានភ្ជាប់តំណភ្ជាប់ទៅកាន់មេរៀនដើម។
   - ការពន្យល់ និងឧទាហរណ៍ជាក់ស្តែងជាភាសាខ្មែរដើម (Original Khmer Explanation)។
   - មេរៀននីមួយៗរួមមាន៖ គោលបំណង, ទ្រឹស្តី, វេយ្យាករណ៍ (Syntax), ឧទាហរណ៍កូដ, ការពន្យល់មួយជួរៗ (Line-by-line breakdown), លទ្ធផលរំពឹងទុក, កំហុសដែលឧស្សាហ៍ជួបប្រទះ (Common Mistakes: Bad vs Good Code), លំហាត់អនុវត្ត, និងកម្រងសំណួរតេស្ត។

3. **Real Sandboxed Java Execution (OpenJDK 21):**
   - បំពាក់ដោយ **Monaco Editor** (ដូច VS Code) គាំទ្រ Syntax Highlighting, ផ្លូវកាត់ក្តារចុច `Ctrl + Enter` (ឬ `Cmd + Enter`), ប៊ូតុង Run, Reset, Copy, និងប្តូរទំហំអក្សរ។
   - ដំណើរការកូដ Java លើ Cloud Sandbox ពិតប្រាកដ (OpenJDK 21 Wandbox Engine) ធានាសុវត្ថិភាពខ្ពស់ មិនដំណើរការកូដដែលមិនទុកចិត្តលើ Main Web Server ឡើយ។
   - គាំទ្រការបញ្ចូលទិន្នន័យតាមរយៈ Scanner (Stdin Input) និងអក្សរខ្មែរ UTF-8 Output។

4. **គម្រោងអនុវត្តជាក់ស្តែងទាំង ៥ (5 Guided Projects):**
   - **Project 1:** Console Calculator (ម៉ាស៊ីនគិតលេខពហុមុខងារ)
   - **Project 2:** Student Grade & GPA System (ប្រព័ន្ធគណនាពិន្ទុ និងនិទ្ទេសសិស្ស)
   - **Project 3:** Bank ATM Simulator (ម៉ាស៊ីនដកប្រាក់ស្វ័យប្រវត្តិ ATM ជាមួយ OOP)
   - **Project 4:** OOP Library Management System (ប្រព័ន្ធគ្រប់គ្រងបណ្ណាល័យ)
   - **Project 5:** Student Management System (ប្រព័ន្ធគ្រប់គ្រងសិស្សជាមួយ Java Collections)
   - គម្រោងទាំងអស់មាន Checklist តម្រូវការ, ករណីតេស្តសាកល្បង (Test Cases), ការណែនាំជំនួយ (Hints), និងដំណោះស្រាយគំរូ (Reference Solution)។

5. **ប្រព័ន្ធតេស្តសមត្ថភាព និងវឌ្ឍនភាព (Quizzes & Progress Tracking):**
   - សំណួរពហុជម្រើស Progressive Difficulty ជាមួយ Hints, Feedback បកស្រាយលម្អិត និង Score Tracking។
   - ការអបអរសាទរ (Confetti Celebration Animation) នៅពេលឆ្លើយត្រូវ ១០០% ឬបញ្ចប់គម្រោង។
   - ការកត់ចំណាំមេរៀន (Bookmarks) និងប្រវត្តិមេរៀនដែលបានរៀន។

6. **ការផ្ទៀងផ្ទាត់ និងរក្សាទុកទិន្នន័យឆ្លងឧបករណ៍ (Supabase Persistence):**
   - គាំទ្រ User Registration, Login, Password Reset តាមរយៈ Supabase។
   - ការពារទិន្នន័យដោយ Row Level Security (RLS)។
   - មាន **Offline / Local Storage Mode** ស្វ័យប្រវត្តិ អាចប្រើប្រាស់បានភ្លាមៗដោយមិនចាំបាច់មានគណនី ឬពេលគ្មានអ៊ីនធឺណិត។

7. **វចនានុក្រមបច្ចេកទេស (Khmer-English Technical Glossary):**
   - ពាក្យបច្ចេកទេស Java សំខាន់ៗ (OOP, JVM, Bytecode, Garbage Collector, Static, Interface...) ជាមួយការបញ្ចេញសំឡេងជាភាសាខ្មែរ និងឧទាហរណ៍កូដ។

## 🚀 ការដំឡើង និងដំណើរការក្នុងម៉ាស៊ីន (Local Setup)

### ១. លក្ខខណ្ឌតម្រូវ (Prerequisites)
- **Node.js** v18+ (បានធ្វើតេស្តដោយជោគជ័យលើ Node v24)
- **npm** v9+

### ២. ជំហានដំឡើង
```bash
# ១. ចូលទៅកាន់ថតគម្រោង
cd "JAVA Website"

# ២. ដំឡើងកញ្ចប់ Packages
npm install

# ៣. ដំណើរការ Development Server
npm run dev
```
បើក Browser របស់អ្នកទៅកាន់ `http://localhost:5173`។

### ៣. ដំណើរការ Test Suites ផ្ទៀងផ្ទាត់ប្រព័ន្ធ
```bash
# ១. ផ្ទៀងផ្ទាត់ប្រព័ន្ធមេរៀន ទាំង ៨ Modules, ២៧ មេរៀន, និង ៥ គម្រោង
npx tsx test/verify_platform.ts

# ២. ផ្ទៀងផ្ទាត់ Java Playground & Isolated Sandbox Execution (Valid code, Compile/Runtime Errors, Stdin, Timeouts, Limits)
npx tsx test/verify_playground.ts
```

## 🔐 ការកំណត់ Supabase Cloud Database (Optional)

វេទិកានេះអាចដំណើរការយ៉ាងរលូន **១០០% តាមរយៈ Local Storage** ដោយមិនបាច់ភ្ជាប់ Database ក៏បាន។ ប៉ុន្តែដើម្បីបើកមុខងារ Sync ឆ្លងឧបករណ៍សម្រាប់សិស្ស៖

1. បង្កើត Project ថ្មីនៅ [supabase.com](https://supabase.com)
2. បើកផ្ទាំង **SQL Editor** ក្នុង Supabase Dashboard រួចចម្លងកូដពី `supabase/schema.sql` ទៅដំណើរការ (Run)។
3. បង្កើត file `.env` ក្នុង root directory ដោយចម្លងពី `.env.example`:
```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-actual-anon-key
```
4. Restart development server (`npm run dev`)។

## ☕ ការកំណត់ Java Execution Service & Sandbox Architecture

ប្រព័ន្ធរត់កូដ Java របស់ Khmer Java Academy ត្រូវបានរចនាឡើងយ៉ាងម៉ឺងម៉ាត់ ដោយ**មិនដំណើរការ Untrusted Code លើ Main Web Server ឡើយ**៖

1. **លំនាំដើម (Default Sandbox):**
   - ដំណើរការកូដ Java លើ Cloud Sandbox ដាច់ដោយឡែក (OpenJDK 21 Wandbox Engine)។
   - គាំទ្រ UTF-8 Console Encoding ពេញលេញ ធានាការបង្ហាញអក្សរខ្មែរ (`សួស្តីកម្ពុជា`) ត្រឹមត្រូវ គ្មានបញ្ហា `?` (Mojibake)។
   - បំបែកច្បាស់លាស់រវាង Output (`stdout`), Compilation Error (`javac diagnostic`), Runtime Error (`stack trace`), និង Output Comparison (`Expected Output vs Actual Output`)។
   - អនុវត្តកម្រិតការពារ៖ Execution Timeout (១៥ វិនាទី), Code Size Limit (អតិបរមា 50KB), និង Output Size Limit (អតិបរមា 100KB)។

2. **Self-Hosted Docker Runner (ជម្រើសសម្រាប់ស្ថាប័ន / On-Premise):**
   អ្នកអាចរៀបចំ Docker Runner ផ្ទាល់ខ្លួនបានយ៉ាងងាយស្រួល ឧទាហរណ៍តាមរយៈ Piston Engine៖
   ```bash
   # ទាញយក និងដំណើរការ Docker Container
   docker run -d -p 2000:2000 --name java-runner ghcr.io/engineer-man/piston
   ```
   បន្ទាប់មកចូលទៅកាន់ផ្ទាំង **Settings (រូបកង់)** ក្នុង Code Playground រួចបញ្ចូល URL: `http://localhost:2000/api/v2/execute` ហើយចុចប៊ូតុង **"ធ្វើតេស្តការតភ្ជាប់ Runner"**។

3. **ការបិទ / បើកដំណើរការ Runner (Execution Disabled Simulation):**
   - អាចកំណត់ក្នុង `.env`: `VITE_DISABLE_SANDBOX_EXECUTION=true`
   - ឬបិទក្នុងផ្ទាំង Settings ដោយផ្ទាល់។ នៅពេលបិទ ប៊ូតុង "Run" នឹងបង្ហាញស្ថានភាព Disabled ជាមួយការណែនាំ Setup Guide ច្បាស់លាស់ ដោយមិនធ្វើពុតជាដំណើរការកូដឡើយ។
